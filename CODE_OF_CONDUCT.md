# Code of Conduct

## Our Commitment

We are committed to providing a welcoming and inclusive environment for everyone who wants to contribute to or use Uploadista SDK.

## Expected Behavior

- Be respectful and considerate in all interactions
- Use welcoming and inclusive language
- Accept constructive feedback gracefully
- Focus on what is best for the community
- Show empathy towards other community members
- Be patient with newcomers and help them learn

## Community Guidelines

- Collaborate openly and share knowledge
- Give credit where credit is due
- Keep discussions focused and productive
- Respect differing viewpoints and experiences
- Assume good intentions from others

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub repositories (issues, pull requests, discussions)
- Project documentation
- Any other forums created by the project team

## Reporting

If you experience or witness behavior that violates this Code of Conduct, please report it by contacting the project maintainers at:

**Email**: conduct@uploadista.dev

All reports will be reviewed and investigated promptly and fairly. The project team is committed to maintaining confidentiality with regard to the reporter.

## Enforcement

Project maintainers have the right and responsibility to remove, edit, or reject comments, commits, code, issues, and other contributions that do not align with this Code of Conduct.

## Attribution

This Code of Conduct is adapted from common open source community guidelines and the [Contributor Covenant](https://www.contributor-covenant.org/).
